# BZAN 531 course pre setup

A class activity to setup your Python env for a future class. [Dr. Souza](https://scholar.google.com/citations?hl=en&user=twBwrYwAAAAJ) provided `bzan531example.zip`.

**Your task** (while trying to use our class toolset as much as possible) **is to setup a `bzan_531` dir and `.venv` that can run `cat1w.py`** (a `.py` that is in `bzan531example.zip` and leverages a `.dat` file that is also in the `.zip`).
